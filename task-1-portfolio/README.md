# Task 1: Personal Developer Portfolio & Project Showcase

A responsive, modern personal developer portfolio built with semantic HTML5, modern CSS (Flexbox & CSS Grid), and vanilla JavaScript.

## ✨ Features
* **Semantic HTML5 Structure:** Clean separation of Header, Hero, About & Credentials, Skills Grid, Featured Projects, and Contact sections.
* **Responsive Mobile-First Design:** Fluid layout adapting seamlessly across mobile phones, tablets, and desktops.
* **Dark / Light Theme Toggle:** Instant theme switching with preference persistence via `localStorage`.
* **Interactive Modals:** Detailed project inspection windows triggered on card clicks.
* **Zero Dependencies:** Extremely lightweight (< 150 KB total) and lightning-fast.

## 🚀 Local Preview
